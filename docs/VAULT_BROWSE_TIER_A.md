# Vault browse — Tier A

**Goal:** Organize many items without becoming Notes (Photos-inspired).

## Shipped
- **Pinned** section (list)
- **Recent** horizontal strip + list body section (`lastCopiedAt`)
- **Everything else** section
- **Search suggestions** (categories, uncategorized, recent titles) when search focused + empty query
- **Uncategorized** filter via suggestion chip
- **Category auto-suggest** on new item (wifi / banking / URL / passwords / codes)
- Recent strip **excludes pinned** (less duplicate)

## Data
- `ClipItem.lastCopiedAt` stamped on copy (existing)

## Non-goals (Tier B+)
- Nested folders
- Cloud AI clusters
- A–Z scrubber (optional later)

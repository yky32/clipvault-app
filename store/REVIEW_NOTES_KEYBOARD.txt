ClipVal Keyboard — App Review notes

WHAT IT IS
A custom keyboard that inserts short vault snippets (pinned / recently used)
the user already saved in ClipVal. Search + tap-to-insert. Not a general typing keyboard.

FULL ACCESS
iOS requires “Allow Full Access” for a keyboard to read an App Group shared with
the containing app. ClipVal uses Full Access only to read a local JSON snapshot.
The extension:
• does not log keystrokes
• does not access the network
• does not upload data

SENSITIVE ITEMS
Items marked sensitive in ClipVal are excluded from the keyboard UI entirely.

HOW TO TEST
1. Enable ClipVal keyboard + Full Access
2. Open ClipVal, pin an item
3. Notes → ClipVal keyboard → search/tap → text inserts
4. Globe returns to system keyboard
